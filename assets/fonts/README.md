# Bundled diagram fonts

Noto Sans Regular and Noto Sans Math Regular are distributed under the SIL Open Font License 1.1. See OFL.txt for the copyright notice and licence.

Unmodified upstream files, retrieved 26 November 2026:

- https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMath/NotoSansMath-Regular.ttf
- https://github.com/notofonts/noto-fonts/blob/main/LICENSE

The renderer uses Noto Sans for text, with Noto Sans Math for glyphs missing from the text font. Bundling both makes image generation reproducible and works offline.
